Modifications: the two self-contained glTFs were repacked as GLBs, preserving meshes, skins, textures and all clips. The mech is a small secondary study in the reading area; the entrance robot is original code-native geometry. Runtime scale, placement, and a muted warm-white / green material palette adapt them to the gallery. The arm source is static and is posed using its existing joint nodes at runtime; the mech has 17 animation clips and the flying companion has 8. Only idle/flying-idle clips are played; no weapon or combat animations are used.

The redistributed Quaternius License.txt has an inconsistent “Ultimate Platformer Pack” header; its CC0 dedication agrees with the actual Ultimate Space Kit primary page and the redistributor's attribution record. The license text is retained with trailing whitespace normalized in Quaternius-License.txt.
