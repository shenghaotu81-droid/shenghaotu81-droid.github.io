## 本次最终验证：无浏览器、无 GPU

在 Node 中通过无绘制替身构建 `createGallery()` 的实际场景，没有复制另一份碰撞布局，没有创建 WebGL 上下文或执行渲染循环。

- 实际整圈海岸路径：3,631 个 1/60 s 物理步，约 61 秒虚拟步行，无需跳跃。
- 从室外步行穿过前门、经过室内四区，并步行退出。
- 玻璃阻挡跑跳；木平台可站立步行；薄墙与低天花板不穿透。
- 实测跑/走位移比约 1.60，跳高约 0.65 m；空中不能再次起跳。
- 低天花板夹具限制跳高约 0.349 m，墙角落地状态稳定。
- 通过实际键盘绑定派发 Shift、W/S、空格、E、R、Esc 事件，驱动同一份生产运动输入。跳跃接线、按键重复、暂停与阅读阻止移动均通过。
- 四区附近读取回调正确，资源清单与中英界面键完整。
- 软件渲染器检测规则、JavaScript 语法、JSON、GLB 文件头/大小/动画、Git 空白检查通过。
- `python3 -m http.server` 短时启动后检查 20 件页面、脚本、JSON、模型资源，均返回 200，然后自动退出。

最终 CPU 场景检查耗时约 0.5 秒，0 个 GPU 上下文。Node heap 限制 128 MiB；实测进程峰值 RSS 约 270 MiB（含几何数组及模块）。模型负载仍为 901,608 bytes。
